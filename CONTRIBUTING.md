# Cómo colaborar

Gracias por ayudar a que TrackRetail sea más útil para el trabajo diario.

## Reportar un error

Usa la [plantilla de errores](https://github.com/mashmellows172-cmd/track-retail/issues/new/choose). Describe qué intentabas hacer, qué ocurrió y cómo reproducirlo. Indica el dispositivo y navegador; si adjuntas capturas, elimina nombres, folios y otros datos personales.

## Proponer una mejora

Explica el problema que resolvería, quién la usaría y un ejemplo de uso. Una situación concreta ayuda más que una lista de funciones.

## Enviar cambios

1. Sigue la [guía de configuración](docs/CONFIGURACION.md).
2. Crea una rama con un nombre descriptivo.
3. Mantén cada cambio centrado en un problema.
4. Ejecuta las comprobaciones disponibles en la rama y documenta cualquier fallo.
5. Abre un pull request indicando el comportamiento anterior, el nuevo y cómo lo verificaste.

Para cambios de interfaz, revisa móvil y escritorio, navegación por teclado y estados de carga y error. Para cambios en comisiones, aporta ejemplos con resultados esperados y confirma las reglas comerciales antes de modificar los tramos.

No incluyas credenciales, bases reales ni boletas con datos personales. Consulta [SECURITY.md](SECURITY.md) para problemas de seguridad.
